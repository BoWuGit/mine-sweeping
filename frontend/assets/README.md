# 音效文件

这个目录包含游戏所需的音效文件。

## 需要的音效文件

- `reveal.mp3` - 揭开格子时的音效
- `flag.mp3` - 标记地雷时的音效  
- `explosion.mp3` - 踩到地雷时的爆炸音效
- `victory.mp3` - 游戏胜利时的音效

## 获取音效文件

你可以从以下来源获取免费的音效文件：

1. **Freesound.org** - 免费音效库
2. **Zapsplat** - 免费音效网站
3. **OpenGameArt** - 游戏音效资源
4. **BBC Sound Effects** - BBC免费音效库

## 音效要求

- 格式：MP3
- 时长：0.5-2秒
- 音量：适中，不要过于刺耳
- 风格：简洁、清晰

## 替代方案

如果暂时没有音效文件，游戏仍然可以正常运行，只是没有音效反馈。

## 自定义音效

你可以替换这些音效文件，只需保持相同的文件名即可。
